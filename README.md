# TikTok Link Inspector

A small MCP server for inspecting public TikTok link metadata.

## Current scope

The first version is intended to retrieve public metadata exposed by TikTok's oEmbed endpoint (such as the video title, creator, and embed HTML when available).

It does **not** download or watch the video, extract audio, or bypass TikTok access controls. A TikTok URL alone does not guarantee that the video itself can be analyzed.

## Status

Project scaffold. Server implementation and deployment configuration are the next steps.
